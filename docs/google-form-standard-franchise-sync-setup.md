# การเชื่อม Google Form เดิมเข้าระบบแฟรนไชส์

ระบบนี้ใช้ Google Apps Script ที่ผูกกับ Google Sheets เดิม ไม่ใช้ Google
Sheets API และไม่ใช้ Service Account จึงไม่ต้องดาวน์โหลดหรือส่งไฟล์กุญแจ
ให้บุคคลอื่น

## การทำงาน

- Google Form เดิมยังส่งคำตอบเข้า Google Sheets ตามปกติ
- Apps Script ส่งเฉพาะข้อมูลคำตอบไปยัง API ของเว็บไซต์ผ่าน HTTPS
- รหัสเชื่อมต่อเก็บใน Script Properties และฝั่ง Supabase เก็บเฉพาะ SHA-256 hash
- การตั้งค่าครั้งแรกนำเข้าข้อมูลเก่าทั้งหมด
- คำตอบใหม่ Sync ทันทีด้วย `onFormSubmit`
- การแก้ไขข้อมูลในชีต Sync ทันทีด้วย `onEdit`
- ระบบตรวจทวนข้อมูลทุกชั่วโมงเพื่อกู้คืนกรณี Trigger ล้มเหลวชั่วคราว
- คอลัมน์ `ระบบ Sync ID` ถูกเพิ่มและซ่อนไว้ เพื่อให้เรียงหรือแก้ไขแถวแล้ว
  ยังอ้างถึงใบสมัครเดิมได้

## ขั้นตอนครั้งเดียวหลังโค้ดขึ้น Production

1. เปิด Google Sheets คำตอบเดิม
2. เลือก **ส่วนขยาย > Apps Script**
3. แทนที่โค้ดเดิมด้วยไฟล์ `docs/google-form-standard-franchise-sync.gs`
4. เลือกฟังก์ชัน `configureGoogleFormSync` แล้วกด **เรียกใช้**
5. อนุญาตสิทธิ์ให้ Apps Script เมื่อ Google แสดงหน้าขออนุญาต
6. วางรหัสเชื่อมต่อที่ออกจากระบบ แล้วกดตกลง
7. รอจนฟังก์ชันทำงานเสร็จ การทำงานครั้งนี้จะ Backfill ข้อมูลเก่าทั้งหมด

ไม่ต้องแชร์ Google Sheets ให้ Service Account และห้ามวางรหัสเชื่อมต่อใน
ซอร์สโค้ด, GitHub, Vercel Environment Variables หรือข้อความสาธารณะ

## การตรวจสอบ

1. เปิด Dashboard เจ้าของที่หน้า `/leads`
2. ตรวจจำนวนรายการ **Google Form เดิม**
3. แก้ข้อมูลที่ไม่สำคัญในแถวทดสอบหนึ่งแถว
4. รีเฟรช Dashboard และตรวจว่าใบสมัครเดิมถูกอัปเดตโดยไม่เพิ่มจำนวนรายการ
5. ส่งคำตอบทดสอบใหม่หนึ่งรายการ และตรวจว่าเกิดรายการใหม่เพียงหนึ่งรายการ

หากตั้งค่าใหม่ ระบบสามารถ Backfill ซ้ำได้ เพราะ API ใช้ Sync ID,
payload hash และเบอร์โทรที่ปรับรูปแบบแล้วเพื่อป้องกันข้อมูลซ้ำ
